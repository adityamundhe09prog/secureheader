# Contributing to SecureHeader

Thanks for considering a contribution!

1. Open an issue to discuss substantial changes.
2. Fork the repository and create a focused branch.
3. Install development dependencies with `python -m pip install -e ".[dev]"`.
4. Add or update tests for your change.
5. Run `pytest -q` and `ruff check .`.
6. Submit a pull request describing the change and its test results.

Good first contributions include documentation improvements, additional tests, clearer recommendations, and carefully scoped header checks.

Please keep changes focused and avoid adding network calls to unit tests.
